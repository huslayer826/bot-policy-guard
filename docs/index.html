bot-policy-guard

Audit Renovate, Dependabot, and GitHub Actions dependency automation policy before risky bot defaults reach production.

Install View checks 
$ bot-policy-guard . --fail-on medium
Bot Policy Guard audit
Scanned files: 3
Findings: 4

[HIGH] BPG-RENOVATE-AUTOMERGE-SOAK
Renovate automerge has no release-age soak

[MEDIUM] BPG-GHA-ACTION-NOT-PINNED
Workflow uses 'actions/checkout@v4'

Policy Checks

Automerge control

Flags broad Renovate automerge and dependency bot automerge without a release-age soak.

Review capacity

Detects missing update limits and missing groups that create noisy, hard-to-review dependency PR streams.

Workflow safety

Finds unpinned GitHub Actions and broad token permissions around dependency bot workflows.

Install

pip install bot-policy-guard
bot-policy-guard /path/to/repo --format sarif --output bot-policy.sarif

Output Formats

Text Human-readable terminal reports for local review.
JSON Structured findings for scripts and dashboards.
Markdown Pull request comments, audit notes, and remediation issues.
SARIF Code scanning upload workflows and security reporting.
