# Code of Conduct

This project follows the Contributor Covenant spirit: be respectful, assume
good intent, and keep technical disagreement focused on the work.

Unacceptable behavior includes harassment, threats, discriminatory language,
personal attacks, and publishing private information without permission.

Maintainers may remove comments, issues, commits, or pull requests that violate
these expectations. Repeated or severe violations may lead to a temporary or
permanent ban from project spaces.

To report a problem, use the private security or maintainer contact process
listed in `SECURITY.md`.
